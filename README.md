# Filipino Emigrants Platform

This repository is a deployment-ready starter for the ITD112 Filipino Emigrants project using:

- `client/`: Vite + React + Supabase + Recharts
- `server/`: Node + Express
- `api/`: Vercel serverless entry point for `/api/*`
- `Supabase`: primary database for CRUD

## 2. Local Setup

### Install

```bash
npm install
```

### Supabase Setup

1. Create a Supabase project.
2. Open the SQL editor.
3. Create the `emigrants` table:

```sql
create table if not exists public.emigrants (
  id bigint generated by default as identity primary key,
  year integer not null,
  single integer not null default 0,
  married integer not null default 0,
  widower integer not null default 0,
  separated integer not null default 0,
  divorced integer not null default 0,
  "notReported" integer not null default 0
);
```

4. Copy your:
   - Project URL
   - Anon public key

### Frontend Environment

Copy `client/.env.example` to `client/.env` and replace the Supabase values.

### Server Environment

Copy `server/.env.example` to `server/.env`.

## 3. Run the App

### Frontend

```bash
npm run dev:client
```

Open `http://localhost:5173`.

### Backend

```bash
npm run dev:server
```

API health check:

```text
http://localhost:4000/api/health
```

## 4. What Is Included

- Supabase CRUD for the `emigrants` table
- Dashboard layout with:
  - comparison chart
  - composition chart
  - trend chart
  - distribution chart
  - relationship chart
  - geographic placeholder chart
- Supabase client bootstrap in `client/src/lib/supabase.js`
- Vercel configuration for static frontend + `/api/*` backend routes

## 6. Vercel Deploy

1. Push the repo to GitHub.
2. Import the GitHub repository into Vercel.
3. Vercel should detect `vercel.json`.
4. Add the `client/.env.example` variables in Vercel.
5. Deploy.
