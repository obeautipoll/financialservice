# Supabase CMS

This project is a simple Content Management System built with:

- React 19
- Vite 8
- Plain CSS
- Supabase Auth
- Supabase database

## Environment Variables

Create `client/.env` from `client/.env.example`:

```env
VITE_SUPABASE_URL=<your_supabase_url>
VITE_SUPABASE_ANON_KEY=<your_anon_key>
```

Add the same values in Vercel project environment variables.

## Supabase Setup

### 1. Authentication

In Supabase:

1. Create a project.
2. Go to Authentication.
3. Enable Email/Password sign-in.
4. Create an admin user.

### 2. Database Table

Run this SQL:

```sql
create table if not exists public.landing_page_config (
  id bigint generated by default as identity primary key,
  site_name text not null,
  logo_url text,
  description text not null
);

insert into public.landing_page_config (id, site_name, logo_url, description)
values (1, 'My CMS Site', '', 'Edit this content from the admin dashboard.')
on conflict (id) do nothing;
```

### 3. Row Level Security

Run this SQL to keep the landing page public but restrict updates to authenticated users:

```sql
alter table public.landing_page_config enable row level security;

create policy "Public can read landing page config"
on public.landing_page_config
for select
to anon, authenticated
using (true);

create policy "Authenticated users can insert landing page config"
on public.landing_page_config
for insert
to authenticated
with check (true);

create policy "Authenticated users can update landing page config"
on public.landing_page_config
for update
to authenticated
using (true)
with check (true);
```

## Local Development

Install dependencies:

```bash
npm run install:client
```

Run the app:

```bash
npm run dev:client
```

Open `http://localhost:5173`.

## CMS Behavior

- `/` renders the landing page from Supabase.
- `/admin` shows the login form for logged-out users.
- authenticated users can edit:
  - site name
  - logo URL
  - description
- updates are saved into `landing_page_config`

## Vercel Deployment

Use the repository root as the Vercel root directory.

Environment variables required in Vercel:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

The current `vercel.json` builds the Vite app from `client/`.
